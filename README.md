# Quplets

This repository contains the paper **“Crest continuation and canonical
Euclidean-rhythm selection: a two-frequency cosine model”** and the Python
experiments used to explore and illustrate it.

For coprime integers $1<n<d$, the paper studies the cyclic profile

$$
F_k(x)=k\cos(2\pi d x)+(1-k)\cos(2\pi n x),
\qquad k\in[0,1],\quad x\in\mathbb{R}/\mathbb{Z}.
$$

As $k$ moves from 0 to 1, the $n$ crests that start on the regular
$n$-grid are continued toward the $d$-grid. Their cyclic spacings form a
continuous **Huplet** path and end at a distinguished Euclidean-rhythm
representative, the **Quplet** $Q(n,d)$. At the balanced value
$k_c=n/(n+d)$, the construction also gives the relation
$Huplet(n,d,k_c)=Q(n,n+d)$. When $n$ is even, the central crest undergoes
a symmetric pitchfork and produces a reflected pair of endpoint selections.

## Repository layout

| Path | Contents |
| --- | --- |
| [`main.typ`](main.typ) | Entry point for the paper |
| `00-abstract.typ`–`08-conclusion.typ` | Paper sections |
| [`Figures/`](Figures/) | Curated figures used by the Typst paper |

`Figures/` and `python/figures/` have different roles. Python scripts write to
`python/figures/`; only figures deliberately selected for the paper should be
copied into the root `Figures/` directory.

## Requirements

- [Typst](https://typst.app/) to compile the paper
- Python 3.10 or newer
- NumPy, Matplotlib, SciPy, ipywidgets, and IPython for the notebook and core
  plotting scripts
- scikit-learn and Plotly for the geodesic experiments
- JupyterLab, or an editor with Jupyter notebook support
- Tk support for the older desktop GUI scripts (optional)

One possible local setup is:

```sh
git clone https://github.com/malcolmbraff/Quplets.git
cd Quplets
git switch Article

python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install numpy matplotlib scipy ipython ipywidgets jupyterlab scikit-learn plotly
```

On Windows, activate the environment with `.venv\Scripts\activate` instead.

## Read the paper

Compile the paper once with:

```sh
typst compile main.typ
```

This creates `main.pdf`. During editing, Typst can rebuild it automatically:

```sh
typst watch main.typ
```

## Explore the notebooks

The repository currently contains two interactive guides:

- [`paper_plot_examples.ipynb`](python/notebooks/paper_plot_examples.ipynb)
  presents the main paper's line of thought without proofs.
- [`selector_curves_and_triggering.ipynb`](python/notebooks/selector_curves_and_triggering.ipynb)
  presents the selector curves and provides a live explorer backed by
  `T_k(x).py`.

Open a notebook, select the virtual environment as its Python kernel, and run
all cells from the top. The controls for $n$, $d$, and $k$ redraw the relevant
examples; choose coprime values with $1<n<d$. The main examples use odd $n$,
while the pitchfork example intentionally advances $n$ in even steps.

To start JupyterLab from the repository root:

```sh
jupyter lab python/notebooks
```

## Run individual plots

The command-line trajectory example accepts odd, coprime $n,d$:

```sh
python python/scripts/crest_trajectories_cli.py 5 7 \
  --output crest-trajectories-n5-d7.svg
```

The SVG is written to `python/figures/`. Some exploratory scripts instead open
a desktop window and prompt for parameters, for example:

```sh
python python/scripts/slider_k.py
python python/scripts/crests.py
python "python/scripts/Fk(x).py"
```

## Collaboration workflow

The current paper branch is `Article`. For a change, create a short-lived
branch, commit there, push it, and open a pull request into `Article`:

```sh
git switch Article
git pull
git switch -c your-name/short-description

# Make and review the changes.
git add <files>
git commit -m "Describe the change"
git push -u origin your-name/short-description
```

Before committing, check `git status` and avoid adding generated caches,
virtual environments, or an unintended `main.pdf`.
